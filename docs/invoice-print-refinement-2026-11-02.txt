StockFlow invoice print refinement — 2026-11-02

Delivered
- Existing A4 and 80mm formats share the same saved invoice model. No financial
  posting, inventory posting, GST rule or invoice-numbering change. No SQL migration.
- 80mm now uses compact header/customer spacing and Qty x Rate on one line rather
  than stacking every A4 cell. Empty serials, zero line discounts/taxes, zero total
  discounts/allowances, empty warranty sections and paid-sale credit-zero text are
  omitted. A mixed receipt still retains real serials and warranty information.
- Navy/pink branding, saved business particulars, existing shop-logo behavior,
  pink Grand Total, company footer/terms and brand footer remain available.
- A4 serial column appears only when a captured serial exists; quantity centered,
  amounts right aligned/tabular, numeric cells do not wrap. Repeated table headings
  and row break protection remain in print CSS. No fixed roll-page height.
- Compact toolbar groups navigation/format on the left and print/PDF/new bill on
  the right; browser help is expandable. Checkout is unchanged.
- Captured entered prices and item discounts are read from the original posted
  request for modern allocated-discount invoices. Saved normalized line values
  still supply taxable amounts, tax and line totals; allocation is never deducted
  again. Tax-inclusive prices are labeled. GST component totals and line cess use
  the existing issued GST snapshot.
- Blank references disappear when no payment has one. Original credit entries,
  later collection dates and current outstanding/returns/refunds remain separate
  from original invoice totals, reusing DocumentOperations settlement semantics.
- General sales.notes are unclassified, so they remain in authorized sale details
  and are excluded from customer invoices. Product descriptions and saved company
  terms/footer still print. No new customer-note visibility system was invented.
- Missing original customer/product/company fields no longer fall back to mutable
  current master details. Original GST document snapshots can supply captured
  legacy particulars. Missing data is omitted/identified. Existing InvoiceService
  policy allowing the shop's current saved logo on older invoices is retained.
- E-way preparation's EXTERNAL_UNVERIFIED references are not printed as official
  EBNs. No provider-generated EBN workflow was added by this print change.

Limits
- 58mm is not an implemented format in the current selector; no untested option
  added. Browser PDF output does not prove physical print alignment/cutting.
- Real A4/80mm printers, drivers, margins, paper feed/cutter, scanner hardware and
  actual Windows 150% display scaling require device acceptance.
- Master snapshots missing from old records cannot be reconstructed reliably;
  the print view does not substitute today's customer/catalog values.
- No application/production migration or data modification performed. Production
  two-shop topology and master-isolation release gates remain as recorded in the
  existing audit; these tests do not certify that deployment.
