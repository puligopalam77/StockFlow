Implementation
Shared files: src/StockFlow.Web/wwwroot/css/action-icons.css and js/action-icons.js.
Both application and authentication layouts load these assets. Existing elements
are enhanced in place: icons, click handlers, hrefs, types, permission rendering,
disabled/loading state, confirmation flows and API calls are retained.

One source of size values lives in action-icons.css:
  compact: 26px visible face / 13px icon
  standard: 32px / 16px (including modal close controls)
  touch: 44px / 18px
  action gap: 4px; radius: 4px; background transition: 180ms
Existing charcoal/pink theme tokens are reused; icons remain white. Visible
keyboard focus and reduced-motion preferences are supported. Hidden attributes,
Bootstrap d-none and inline display:none remain effective.

Coarse-pointer devices reserve a separate 44px layout target around the compact
face. Neighboring targets do not overlap. Tables retain horizontal scrolling.
Only the component's icons receive these dimensions; navigation, dashboard,
payment tiles, warning symbols, StockBot and primary text buttons are excluded.

Usage for new controls:
  StockFlowActionIcons.enhance(existingButton, {size:'compact', label:'Edit Product'})
  StockFlowActionIcons.enhance(existingCloseButton, {size:'standard'})
  StockFlowActionIcons.enhance(existingButton, {size:'touch'})
An existing accessible name can supply the label. The native element retains its
own type, icon markup, handler and disabled/loading logic. Size can also be set
using data-action-size. Existing categories/Bootstrap tooltips are preserved;
other actions receive a hover/focus tooltip bounded to the viewport. Dynamic
rows and changed action labels are observed automatically.

Coverage
The adapter covers existing named icon-only table controls throughout the app,
including master lists, staff/roles, sales history, purchase/receipt, inventory
and report tables. It also covers product variant edit/status, attribute and
value removal, optional specification removal, image view/replace/remove,
Receive Stock item edit/remove, New Sale item removal and modal close controls.
Text actions remain text actions, including current barcode Preview/Print/
Reprint controls, purchase links, supplier mapping Remove buttons and report
exports with labels. Existing three-dot actions retain their meaning; none added.
