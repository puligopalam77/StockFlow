Scope and limitations

made in this task. Backend scope/ownership rules remain unchanged. Tests use
in-memory repositories and browser API mocks; they do not certify live database
row-level isolation, physical HP hardware or native mobile dropdown behavior.

The older three-level category-list browser fixture was not used; current
