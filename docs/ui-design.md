# Login and dashboard visual refresh

The interface follows the supplied black/navy and pink references with live HTML forms, a responsive sidebar, KPI cards, charts, and stock activity tables. Desktop uses a split login and fixed sidebar; tablets and phones use a collapsible navigation drawer and reflowed cards. No database migrations are required.

Dashboard values are read from existing products, suppliers, customers, and inventory movements in a consistent read-only snapshot. Empty data is shown as zero/empty state, not the reference image's sample figures. Supplier counts and names are limited to Admin. Inventory and Admin stock adjustments are available from the sidebar. Admin and Sales can open sales/invoices and new sale/dispatch. Admin can edit company/invoice settings; printable invoices are available to Admin, Sales and Service. Forgot password provides administrator contact guidance rather than pretending to send a reset email.

Warehouse asset: `src/StockFlow.Web/wwwroot/images/warehouse-stockflow.png`, generated with the built-in image_gen tool. It is a new photograph matching the reference's visual direction, not an exact extraction of its background.

Premium cinematic industrial warehouse interior at sunset, tall racks packed with brown cardboard cartons on the right, rack uprights and beams vivid hot magenta pink #ff0080, glossy polished concrete floor, loading bay with open delivery truck toward the left background, warm pink dusk sky through loading door. One male warehouse employee seen from behind, black polo shirt, holding a tablet, positioned in right third, small tasteful StockFlow wordmark in white and magenta on back. Wide lens, strong depth and perspective, authentic rich industrial textures, crisp high-quality commercial photography, realistic natural lighting, shadows dark navy. Left third more open and uncluttered for UI overlay. NO UI panels, no input fields, no cards, no charts, no borders, no slogans or other text. Output one high resolution landscape photo suitable for cropping to both portrait side panel and ultra wide dashboard banner.”

Icons are local SVG symbols. Fonts use a local system stack; charts are HTML/CSS and do not require a third-party CDN. The warehouse photograph is a 1536×1024 local asset. Reference slogans remain live text so they stay sharp on different displays.

Browser verification: `tests/StockFlow.UiChecks` uses installed Microsoft Edge. Set `STOCKFLOW_UI_PASSWORD` to a test account password, optionally `STOCKFLOW_UI_USERNAME` (default admin) and `STOCKFLOW_UI_URL` (default http://localhost:5231), then run `dotnet run --project tests/StockFlow.UiChecks`. It checks sign-in, password visibility, dashboard loading, mobile navigation, JavaScript errors and horizontal overflow at 1672, 1440, 1024, 768, 390 and 320 pixels. Screenshots are written to `tests/bin/ui-screens`. Authentication uses the existing account; dashboard queries only read data.
