New Sale cart presentation refinement - 2026-11-02

Scope
Only Items in This Bill and its existing line-adjustment dialog were refined.
The supplied picture is a layout reference. Its products, prices, quantities,
rates and inconsistent illustrative totals were not imported into StockFlow.
No SQL migration, database write, stock posting or costing-policy change.

Delivered
- Pink heading with live line/unit counts and existing confirmed Clear Bill.
- Ten-column navy-header table; compact centered rows and 36px product images.
- Product names wrap to two lines; variant attributes and serial identities use
  compact text with full-value tooltips. SKU appears in its own column once.
- Removed More Details and expanded ordinary metadata. Underlying item identity,
  unit selection and request data remain intact; manual-item editing is retained.
- White editable price/discount/quantity inputs and a 96px desktop stepper.
  Read-only controls are visually distinct. Touch removal has a 44px target.
- Stock displays the current response value. Green/amber uses a supplied minimum
  threshold only; missing thresholds stay neutral. Manual items show Non-stock.
  Scan responses without a minimum threshold deliberately do not imply healthy
  stock just because quantity is positive.
- Ordinary row tax is read-only. Authorized ordinary-bill correction uses the
  existing adjustment dialog via a contextual pencil. Existing tax permission,
  reason requirements and mapped-GST classification restrictions still apply.
- Line totals use existing en-IN money formatting and server quote values.
  Pending/invalid input retains the last confirmed amount, marks it provisional
  and relies on existing quote validity to prevent premature checkout.
- Table scrolling is contained within the cart. Sticky headers and a scroll hint
  keep all ten columns accessible on narrow screens; no page-wide overflow.

Limits
Browser values and roles are synthetic fixtures, not a live-shop transaction or
new database isolation verification. This presentation change does not certify
production two-shop master isolation. Electrical serial and non-serial/manual
paths were exercised; a full live lifecycle in each of Electrical, Bike
Accessories, Clothing and Footwear was not rerun. Profile capability logic was
not changed. Physical scanners, touch hardware, printers and actual OS/browser
150-percent scaling still require device acceptance. Mocked stock/quote data is
test evidence only and never a production data source.
