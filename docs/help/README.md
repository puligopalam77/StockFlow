# StockFlow staff help

Open **Ask StockBot Assist** to type a functionality question or choose a suggested
question. Approved guides are searchable without a configured AI provider. Help
also covers [other application features](application-features.md), including reports,
repairs, stock transfers, cash closing, staff, roles, stores, language and security.
Outside questions display **Contact Super Admin**. Restricted features explain
the missing access; unclear business enquiries ask for clarification rather than
inventing figures. Local matching uses topic words and approved excerpts; it does
not guarantee understanding of every paraphrase. Optional AI improves guide selection.
New guide text without a translation remains English.

Find instructions for everyday shop tasks. Follow the English button names below; when another language is selected, StockFlow also shows translated captions in parentheses. A field marked **\*** must be completed.

| What do you need to do | Guide |
| --- | --- |
| Add a product or understand barcodes and serial numbers | [Products](products.md) |
| Receive goods or place an advance order | [Receiving stock](receiving-stock.md) |
| Create a bill, take payment or print an invoice | [Billing](billing.md) |
| Record a customer return, refund or exchange | [Returns](returns.md) |
| Check warranty dates or record a claim | [Warranty](warranty.md) |
| Fix a missing field, scan problem or unsuccessful save | [Common problems](common-problems.md) |
| Use the Android app, camera, microphone, uploads or printing | [Android app and device features](mobile-and-devices.md) |

Screens and buttons depend on your account permissions. If an option is missing, ask your StockFlow administrator for access. Use a stock location assigned to your account when receiving or selling goods.

Select **Ask StockBot Assist** on any signed-in application screen to read these guides.
The panel suggests questions for the current screen, searches article text and
offers links to screens your account can visit. It works without AI or an external
help service. Help follows the header language choice: English instructions and
screen captions stay visible, followed by translations in parentheses. Search
accepts English or words from the selected translation. All 22 Indian languages
have bundled help packs, so no online translation service is used while reading help.

Current implementation claims and limits are maintained in the
[62-workflow evidence register](../planning/StockFlow-feature-evidence-register-2026-11-02.csv).
Historical phase documents are implementation records, not current checkout
policy or production sign-off. Updated English text may fall back to English
until its translations receive a separate review.

Maintainers: [review and update the guides](content-review.md) whenever a screen or workflow changes.

Use **Ask a question** for instructions selected from these guides when AI help
is configured. Common how-to questions also return approved instructions directly without waiting for AI. Answers include source articles. If an answer is unavailable,
search the guides or use **Contact administrator**. AI help does not change stock or
take payments. Supported live questions use permission-checked server queries; the model does not receive database access. [AI setup and evaluation](ai-setup.md)
explains how to configure the local provider.

For live quantities, use **How much stock is available?** in Help. It reads the
same permitted records as Stock on hand and works without AI. See
[business enquiries](business-enquiries.md) for steps and the meaning of the quantities.
